# GadgetHunter research tool homepage

## Intent
Implement the user's supplied critique and eight-part information hierarchy in the existing GitHub Pages homepage. Lead with inspectable triage evidence. Use research objects (chains, boundaries, constraints, verdicts) as the visual vocabulary. Also restore the existing WebLogic case-study video to the published page.

## Approach
Keep buildless HTML/CSS/JS in `site/`. Retain the repository's Pages deployment. A framework migration adds no value to this presentation; a cosmetic reskin would leave the information hierarchy unresolved. Work in the current clean `modern-scanning` checkout, preserving reviewable uncommitted changes.

## Information and containers
- Hero: proposition on the left, recorded triage on the right. The evidence panel owns one recorded scan, its runtime, partial status, selected chain and source.
- Why and case: explain why candidates need ranking; selectable chain rows control one evidence pane. Rows preserve identity, effect, novelty and mitigation separately. A constrained definition is not a fabricated result.
- Pipeline: ordered connected nodes express data dependencies. Preparation, search and triage are local; selected source analysis uses LLM reasoning and Z3.
- Demonstrations: separate native video players for workbench and WebLogic with captions, provenance and transcripts. A video frame exists for playback, not decoration.
- Evidence: compact table with paper section/table/figure anchors; distinguish original measurements from current engineering.
- Evolution: research and current capabilities in two plain text columns joined by a directional relationship.
- Start: install, scan, analyze command blocks; workbench as an optional disclosure.
- Footer: paper, artifact, repository, documentation.

## Evidence constraints
Use the real recorded fixture scan (2,729 candidates, 512 clusters, partial). Counts are not vulnerability counts. Novelty and mitigation overlap. Do not invent confidence scores, solver results, counts, table references or constrained cases. Link source excerpts and original demo documentation. WebLogic demonstrates filter decisions and reachable sinks, not executed exploitation.

## Visual constraints
Off-white paper, dark ink, precise rules, monospaced traces and teal selection; verdict colors carry meaning with text labels. No gradients, decorative badges, pill CTA group, repeated rounded cards or KPI billboard. Natural headings without middle-dot separators or implementation filenames. Responsive stacking, keyboard navigation and reduced-motion support.

## Validation
Check all relative assets under the actual publication root, both MP4s and caption tracks, chain-selection behavior, clipboard outcomes, HTML anchors, mobile overflow and paper provenance. Do not claim a browser check if no browser is available.
