Workflow overview
GadgetHunter combines static taint analysis, LLM-assisted semantic reachability analysis, and SMT-based path feasibility checking for Java deserialization gadget chains.

Target artifacts
Upload the target application and its dependencies. This demonstration uses a Java test program compiled to bytecode.

Candidate generation
Set the search time limit and select automatic taint rules. Candidate generation uses static analysis and does not invoke an LLM.

Coverage diagnostics
Inspect the saved candidate-generation results and coverage diagnostics. Partial coverage does not rule out additional gadget chains.

Candidate triage
Review the ranked candidate clusters. Novel denotes no match to a catalogued gadget-chain family; it does not establish a new vulnerability.

Source-level analysis
Supply candidate chains and corresponding Java source code for region-based semantic reachability analysis and constraint extraction.

Saved analysis report
We now import a previously generated report for a separate, benign test case. No new source analysis is executed in this demonstration.

Feasibility result
FEASIBLE indicates satisfiability of the extracted constraints under the analysis model. It does not establish exploitability in the target environment.

Call chain and constraints
Inspect the call chain and extracted constraints to assess the data-flow relationships and path conditions represented by the analysis.

Source inspection
Examine the corresponding method implementation and the complete analysis record to review the basis for the reported result.

Report export
Export the analysis report as JSON to support manual review, independent validation, and subsequent analysis.
