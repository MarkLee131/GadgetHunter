06 / Run it on your target

Start with an archive.

Python 3.10+ and JDK 17+ on PATH. Point the scanner at a JDK matching your target. An API key is only needed for the optional analysis stage.

  1. Install

    Clone the current scanning branch and install its Python dependencies.

    git clone -b modern-scanning https://github.com/MarkLee131/GadgetHunter && cd GadgetHunter
python3 -m venv .venv && source .venv/bin/activate
python -m pip install -r requirements.txt

  2. Scan

    JARs, fat JARs and WARs work here. Add --lib for unbundled dependencies.

    python scan_candidates.py --app /path/service.jar \
  --java-home /path/to/target-jdk --output scans/service \
  --collector fair --timeout 600 --heap-mb 6144

  3. Analyze

    Set OPENAI_API_KEY, supply matching Java sources and start with one representative.

    cd multi-agents
python main.py --chains-file ../scans/service/chains.review \
  --project-root /path/to/sources --chain-index 0
Prefer the browser workbench?

Run from the repository root, then open localhost:8765.

python workbench.py --java-home /path/to/target-jdk --collector fair
